# «Волнуй» — сайт студии анимации

Сайт сверстан по макетам (Главная, Плеер/страница мультфильма, Профиль, Ивенты, Вход, Регистрация, Ошибка 404, Меню).
Стек: **HTML + CSS + JavaScript** на клиенте, **Node.js** на сервере, база данных **SQLite (SQL)**.

## Запуск

Нужен только **Node.js версии 22.13 или новее** (https://nodejs.org). Ставить пакеты через `npm install` **не нужно** —
используются только встроенные модули Node.js, в том числе встроенная SQLite (`node:sqlite`).

```bash
cd volnuy-site
npm start            # или: node server.js
```

Откройте http://localhost:8081

На Windows можно просто запустить `start.bat` двойным щелчком.

При первом запуске автоматически создаётся файл базы `db/volnuy.db` из `db/schema.sql` (структура) и `db/seed.sql` (начальные данные).
Чтобы начать с чистой базы — `npm run reset-db` (или удалите `db/volnuy.db`).

**Демо-аккаунт:** `demo@volnuy.ru` / `demo123` (можно войти и по `@imya`).

## Страницы

| Адрес | Файл | Что умеет |
|---|---|---|
| `/` | `index.html` | Первый экран, ценности студии со своим скроллбаром, новости из БД (картинка в повёрнутой карточке меняется при наведении), каталог мультфильмов из БД, кассовый сбор с прогрессом и формой поддержки |
| `/film?id=1` | `film.html` | Карточка мультфильма, кнопка Play (плеер; если видео ещё нет — экран «скоро»), лента «Еще», «Больше о мультфильме», рецензии из БД |
| `/profile` | `profile.html` | Аватар, имя, @имя, редактирование, уровень и опыт, полученные карточки (карусель), «Просмотрено» |
| `/events` | `events.html` | Карточная игра «Волнение»: рулетка карт, поклон боковых карт победителю, случайная карточка (3 попытки в день), архив ивентов |
| `/login`, `/register` | модальное окно | Вход по почте или @имени и регистрация во всплывающем окне на текущей странице |
| любой несуществующий | `404.html` | Страница ошибки 404 |

Меню (бургер справа в шапке) и подвал с формой «Рецензия → Поделиться...» общие для всех страниц — их рисует `js/common.js`.

### Опыт и уровни
Просмотр мультфильма +10, рецензия +15, прокрутка в «Волнении» +5, новая карточка +20, поддержка студии +1 за каждые 100 ₽ (до 50).
Уровень = опыт / 100 + 1, полоска показывает прогресс внутри уровня (как «66/100» в макете).

## Структура

```
server.js            — HTTP-сервер и API (без зависимостей)
db/schema.sql        — таблицы БД
db/seed.sql          — начальные данные (мультфильмы, новости, рецензии, карточки, демо-пользователь)
public/              — всё, что отдаётся браузеру
  *.html             — страницы
  css/style.css      — общие стили (шапка, меню, подвал, кнопки, модальные окна)
  css/*.css          — стили отдельных страниц
  js/common.js       — общий код: API, шапка/меню/подвал, уведомления
  js/*.js            — логика отдельных страниц
  img/               — графика, вырезанная из макетов (SVG — векторная, без потери качества)
  fonts/             — шрифт Montserrat (работает без интернета)
```

### Таблицы БД
`users`, `sessions`, `films`, `film_views`, `reviews`, `news`, `events`, `cards`, `user_cards`, `fundraising`, `donations`.
Пароли хранятся в виде хэша scrypt с солью, вход — через cookie-сессию (HttpOnly).

### API
| Метод | Адрес | Назначение |
|---|---|---|
| POST | `/api/register` | регистрация `{email, password, password2}` |
| POST | `/api/login` | вход `{login, password}` |
| POST | `/api/logout` | выход |
| GET/PUT | `/api/me` | текущий пользователь / изменить имя и @имя |
| GET | `/api/profile` | профиль, карточки, просмотренное |
| GET | `/api/films`, `/api/films/:id` | каталог, мультфильм с рецензиями |
| POST | `/api/films/:id/view` | отметить просмотр |
| GET/POST | `/api/reviews` | рецензии |
| GET | `/api/news` | новости |
| GET | `/api/events` | ивенты, карточки сезона, оставшиеся попытки |
| POST | `/api/events/:id/spin` | «Крутить» |
| GET | `/api/fund`, POST `/api/fund/donate` | кассовый сбор |

## Что можно поменять

* **Мультфильмы, новости, карточки** — в `db/seed.sql` (затем `npm run reset-db`) или прямо в базе любым SQLite-редактором (например, DB Browser for SQLite).
  Названия «Маяк», «Медуза», «Кит» и описания к ним — временные заглушки: в макетах у этих постеров названий нет.
* **Видео** — укажите ссылку в поле `films.video_url` (например `/video/burya.mp4`, положив файл в `public/video/`) и поставьте `status = 'released'`.
* **Порт** — переменная окружения `PORT` (по умолчанию 8081).
* **Перенос на MySQL** — `schema.sql` написан на почти стандартном SQL. Для MySQL замените `INTEGER PRIMARY KEY AUTOINCREMENT` на `INT AUTO_INCREMENT PRIMARY KEY`,
  уберите строку `PRAGMA`, а в `server.js` замените `node:sqlite` на пакет `mysql2`.

Оплата в «Поддержать студию» — демонстрационная: сумма только сохраняется в базе, реальный платёж не проводится.
